# Frontend

Aplicacion React + TypeScript construida con Vite.

## Instalacion

```powershell
npm install
```

## Desarrollo

```powershell
npm run dev
```

La aplicacion queda en `http://localhost:5173`. Vite redirige las solicitudes `/api` a `http://localhost:8000`.

## Build

```powershell
npm run build
```

El resultado se genera en `frontend/dist/`, que no se versiona.
